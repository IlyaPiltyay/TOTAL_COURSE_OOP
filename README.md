# Вакансии на hh.ru

Программа для получения, сохранения и управления информацией о вакансиях с платформы [hh.ru](https://hh.ru) в России.

## Описание

Данная программа позволяет:

- Получать информацию о вакансиях с платформы hh.ru.
- Сохранять данные о вакансиях в файл.
- Удобно управлять данными: добавлять, фильтровать и удалять вакансии.
- Запуск всех класссов в модуле main.py
